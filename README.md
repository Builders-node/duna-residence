# Duna Residence

Премиальный сайт-конфигуратор для выбора апартаментов, по образцу интерактивных 3D-каталогов недвижимости. Навигация: **фасад здания → этаж → квартира → планировка**.

## Стек
- **Next.js 15** (App Router) + React 19 + TypeScript
- **Tailwind CSS v4** — дизайн-система (тёмная «люксовая» палитра, золото/айвори)
- **Framer Motion** — переходы между экранами
- Всё на векторе (SVG): фасад, планы этажей, планировки квартир — **без внешних картинок**

## Запуск
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # прод-сборка (46 страниц квартир пре-рендерятся)
npm start
```

## Структура
```
app/
  page.tsx                 # Главная: hero + интерактивный конфигуратор + о резиденции
  apartments/page.tsx      # Каталог всех квартир с фильтрами и сортировкой
  apartment/[id]/page.tsx  # Страница квартиры с большой планировкой
  layout.tsx · globals.css # Шрифты (Cormorant + Inter) и дизайн-токены
components/
  Explorer.tsx      # Оркестратор: фасад → этаж → квартира + контекстная панель
  BuildingFacade.tsx# Интерактивный 2.5D-фасад башни (подсветка этажей)
  FloorPlate.tsx    # План этажа с кликабельными квартирами
  FloorPlan.tsx     # Векторные планировки (5 типов: студия…пентхаус)
  ApartmentCard.tsx · Header · Footer · Legend
lib/
  data.ts           # ДЕМО-данные: 46 квартир, 12 этажей (генерируются)
  types.ts · status.ts
```

## Как подключить реальные данные
Вся «начинка» — в `lib/data.ts`. Замените генератор `generateApartments()` на свой массив квартир
(площадь, цена, статус `available|reserved|sold`, этаж, координаты на плане этажа `plate`).
Планировки в `components/FloorPlan.tsx` — координаты комнат; можно заменить на ваши PNG/SVG-планы,
подставив `<img>`/`<svg>` вместо генерируемых `PLANS`.

Изображения и цифры сейчас демонстрационные.
